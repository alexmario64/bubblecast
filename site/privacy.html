Bubblecast

Privacy policy

Last updated: October 23, 2026

Bubblecast is a free desktop app that runs entirely on the streamer’s own computer. It combines live chat from Twitch, YouTube, TikTok and Kick into an OBS dock and overlay. There is no Bubblecast server or cloud service, and the developer receives no data from the app.

Each streamer connects YouTube and Kick through their own free developer app. This policy covers Bubblecast as used through any of those apps.

What Bubblecast accesses

  • Twitch. When you connect Twitch, Bubblecast uses the official Twitch API. It sends chat messages you write, runs polls you start, and reads your stream’s viewer count, chat badges and channel point redemptions.
  • YouTube. When you connect YouTube, Bubblecast uses the official YouTube Data API through Google sign-in with the youtube.force-ssl permission. It finds your live streams, reads their chat and viewer count while you are live, sends chat messages you write, and starts and ends polls you create. It does not upload, edit or delete videos, and it does not read your email, contacts or other Google data.
  • Kick. When you connect Kick, Bubblecast uses the official Kick API with the user:read, channel:read and chat:write permissions. It reads your user name, finds your channel’s live status and viewer count, and sends chat messages you write.
  • Live chat. Public live chat is read so it can be shown in the dock and on your stream.

Where data is stored

Everything stays on your computer, in Bubblecast’s data folder (%APPDATA%\Bubblecast on Windows):

  • Sign-in tokens for Twitch, YouTube and Kick, and your own app keys, are stored in files readable only by your user account.
  • Your settings and stream links are stored locally.
  • Recent chat messages are kept in memory and in a short local history so the dock can reload.

Bubblecast never sends this data to the developer or to anyone other than the platform you are using (Twitch, Google/YouTube, TikTok or Kick), and only to perform the action you asked for.

Google user data

Bubblecast’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the features described above, is not transferred to anyone, is not used for advertising, and is not read by people.

Removing access

  • In Bubblecast, click Disconnect for Twitch, YouTube or Kick. This deletes the stored token and revokes it with the platform.
  • You can also remove access at any time at myaccount.google.com/permissions (Google) or twitch.tv/settings/connections (Twitch).
  • Uninstalling Bubblecast and deleting its data folder removes all local data.
